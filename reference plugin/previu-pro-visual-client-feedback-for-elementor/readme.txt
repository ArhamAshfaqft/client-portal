== Description ==

Previu Pro extends the free Previu – Visual Client Feedback for Elementor plugin with advanced features for agencies and teams.

**Pro Features:**

* **File Uploads** — Clients can attach images, videos, PDFs, documents, and ZIP archives to their feedback 
* **Voice Notes** — Clients record audio notes directly in the browser
* **Screenshot & Annotate** — Capture full-page or visible screenshots for reference
* **Slack Notifications** — Get instant Slack messages when clients leave feedback
* **White-Label** — Replace Previu branding with your agency logo and name
* **Media Library** — Browse client-uploaded files inside the Elementor editor and drag them into widgets

== Installation ==

1. Install and activate the free Previu – Visual Client Feedback for Elementor plugin
2. Upload this plugin to `/wp-content/plugins/previu-pro-visual-client-feedback-for-elementor/`
3. Activate through the 'Plugins' menu in WordPress
4. Go to Previu → Settings to configure Pro features
